# Open materials in default applications

Double-click an image, video or general file tile (including its filename) to request the system default application. Text cards keep their existing text-selection/edit behavior; drag handles, menus and destructive buttons do not launch apps. Existing operation lock suppresses duplicate opening requests, and IPC failures remain visible without deleting materials.

Native manager-only IPC resolves an existing non-text material by ID, validates its name and canonical source under the asset folder, then creates a named copy under `opened/<id>/<original-name>` for correct file association. Original assets/session are unchanged. Existing opening copies are retained instead of overwritten, so external edits to the copy are not lost on reopen; they do not automatically update the material bundle. Windows uses ShellExecuteW directly; macOS/Linux use open/xdg-open without shell interpolation. Successful launch lowers the manager's always-on-top state so the external app can appear; normal manager activation restores its existing topmost behavior.
