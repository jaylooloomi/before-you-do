# before-you-do app icon

The current icon is the user-supplied white interwoven symbol on a charcoal rounded tile, approved on 2026-10-26. The source image is preserved without redrawing at `src-tauri/icons/before-you-do-master.png` (1254 × 1254 RGBA, transparent exterior corners).

Run `python scripts/icons.py` with Pillow to export the 1024px PNG, nine Windows ICO sizes, macOS ICNS, 32px tray RGBA, and 128px in-app artwork. The exporter also writes `artifacts/icon-size-check.png` for visual inspection on light and dark backgrounds.

The executable icon, tray and title bar all use these exports. Existing promotional images and historical screenshots may show the previous icon.
