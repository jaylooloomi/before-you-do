# before-you-do app icon

Approved on 2026-11-01: a coral octopus with eight distinct arms, holding a text card and an image card. This simplified mascot represents reusable AI instructions and collected task materials. Navy rounded tile with transparent exterior corners. Master: `src-tauri/icons/before-you-do-master.png`.

Run `python scripts/icons.py` with Pillow to export PNG, nine Windows ICO sizes, macOS ICNS, 32px tray RGBA and 128px in-app artwork. `artifacts/icon-size-check.png` previews actual small sizes on light and dark backgrounds.

Desktop exports trim transparent fringe and fit the visible tile within 1008px of the 1024px canvas. Executable, system tray, title bar and both README inline title logos use these exports. Historical screenshots may retain previous artwork.
