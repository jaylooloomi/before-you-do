# 三欄素材工作台改版

日期：2026-10-30；分支：codex/swiss-workspace-layout。

## 需求與限制

以使用者選定的瑞士極簡概念圖為布局基準：頂部頁面導覽、左側角色／短句、中間素材整理、右側預覽／資訊與固定匯出操作。實際字體、文字、鍵位與資料必須來自程式狀態，不沿用示意圖的假檔案資訊。保留淺／深／跟隨系統、四語、Alt+H、Ctrl+Shift+F6～F10、截圖／錄影、影片播放、所有短句／設定／草稿。禁止使用 Computer Use、桌面鍵鼠注入。未授權合併 main 或公開 Release。

## 實作順序

1. 重整主視窗：把導覽移至頂部、角色移到左側；保留原本編輯器／儲存／退出保護與各角色狀態。
2. 素材頁改為中間清單＋右側 inspector。選取狀態依素材 id 保留，排序／刪除後採有效 fallback；文字／圖片／影片／檔案均可預覽。
3. 檢視真實名稱、種類、大小、媒體尺寸／時長、文字字數；不存在的建立時間不捏造。影片保留播放／暫停／進度／音量，同時最多一個播放器播放。
4. 把擷取／新增操作固定在清單下方；匯出／複製固定 inspector 底部。偏好與快捷鍵放可展開設定，不淹沒素材。
5. 左側短句在素材模式提供獨立複製入口及情境說明，選取或複製不離開素材頁、不改已儲存資料。頁面切換需先 flush 素材，不丟草稿。
6. 以 CSS 變數實現清楚的淺／深主題、寬螢幕三欄、窄視窗可展開預覽。初始視窗以螢幕工作區限制適合的寬度，不放大超出螢幕。

## 測試矩陣

- Navigation：頂部三入口、角色切換、搜尋／排序、快捷鍵與返回流程、原有草稿跨頁保留。
- Materials：空資料、文字修改與復原、圖片／影片／檔案、選取、排序、移除選取項 fallback、匯出及複製。
- Preview：正確 MIME、真實 metadata、載入與失敗提示、影片解碼播放／seek／音量、單一播放、離頁停止、不自動播放。
- Async：重複提交防呆、metadata 過期結果不能覆蓋新選取、素材 flush 失敗不得離頁或清空草稿。
- Layout：1280×860、1920×1080、940×820、780×680；操作無重疊或遮擋，鍵盤可達，四語長文字、淺深主題。
- Regression：JS、Component、完整 Playwright（console/pageerror）、Rust、正式 build、隔離原生 WebView 驗證與截圖檢視。
- Upgrade：如開啟新版，先備份檔案及記憶體角色／草稿／設定／素材，再正常退出；新舊資料 hash 與狀態驗證一致。

每個里程碑結果另記於 docs/qa/SWISS_WORKSPACE_LAYOUT_RESULT.md。不將單純 build 成功視為全部驗證通過。
