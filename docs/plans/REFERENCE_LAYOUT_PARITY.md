- 檢查切換、刪除或重新渲染後是否有殘留播放；清理已移除素材的預覽快取。
- 檢查選取／排序／刪除 fallback、未完成非同步資訊不能覆蓋新選取。
- 儲存失敗必須保留草稿並阻止離頁，按鈕／選單不能繞過 busy。
- 原有短句、設定、素材與記憶體草稿不改寫；測試使用隔離 bridge／原生 profile，不用 Computer Use。
