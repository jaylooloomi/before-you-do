## 繁體中文

### 新功能與修正

- **內建提示詞跟隨語系**：繁中、簡中、英文、日文切換時，12個角色未修改的內建名稱、正文與情境會切換，Alt+H也貼入對應語言。
- **保護你的文字**：新增、匯入、修改過的短句保留原文，自訂標記會隨儲存與JSON往返保留。切語系不改寫已存檔、不清除角色草稿。舊資料僅以原始名稱、正文與情境精確辨識；沒有來源標記的完全相同歷史副本仍可能被視為內建。
- **啟動失敗可恢復**：讀取失敗顯示錯誤與重新載入，阻止未完成初始化的編輯區誤儲存。
- **Unicode字數一致**：名稱、正文與情境和Rust採相同計數，emoji不再被UTF-16限制提前截斷或誤拒絕。
- JSON嚴格型別與逐筆欄位錯誤、匯入前名稱預覽、目前角色已存JSON複製匯出。
- 外部AI改檔／刪檔的覆寫保護、UTF-8 BOM相容、Unicode全半形與多關鍵字搜尋。
- 操作說明跟隨自訂快捷鍵，情境提示明確標示不會貼入正文。

### 下載與升級

- Windows x64：完整解壓縮windows-x64.zip，讓WebView2Loader.dll與before-you-do.exe放在一起。需要Microsoft Edge WebView2 Runtime。
- Mac M系列／Intel：選擇對應ZIP，移入Applications並允許輔助使用／必要的輸入監控權限。Mac尚未實機驗證。
- 升級前先儲存所有角色要保留的草稿，再從系統匣完整退出舊版；已存短句與設定沿用。草稿只在記憶體，不會在強制終止後自動復原。
- 版本未簽章，Mac未公證，沒有自動更新。貼入會取代剪貼簿，不會送出訊息。

### 驗證

發布提交經Windows、Mac Apple Silicon與Intel建置及Node/Rust單元測試。下載包檢查版本、CPU架構、必要檔案與ZIP完整性，附SHA256SUMS.txt。

本機兩輪完整QA各37項Node、6項Component、36次Rust測試執行（含11項重複模組測試）、27項Chromium E2E通過；1項會註冊系統快捷鍵的測試略過。E2E使用IPC替身，原生提交以Rust狀態機驗證；未宣稱跨程序貼上、Mac硬體或系統退出已完整實測。Rust行覆蓋率受profiler runtime限制未取得。詳見TEST_SUMMARY.md。

## English

### What's new

- **Built-in prompts follow your language:** pristine names, bodies and scenarios across all 12 roles switch between English, Traditional Chinese, Simplified Chinese and Japanese. The picker pastes the matching language.
- **Your words stay yours:** added, imported and customized snippets retain their text and persist explicit custom ownership. Changing language does not rewrite files or discard role drafts. An identical historical copy without ownership metadata cannot be distinguished from a built-in.
- Recoverable startup errors with Reload and a protected partially initialized editor.
- Consistent Unicode field limits, including emoji at boundaries.
- Strict AI JSON validation, entry-level errors, bounded import previews and saved-role JSON export.
- External-file edit/deletion protection, UTF-8 BOM support and normalized multi-keyword search.
- Shortcut-specific help and clear scenario-only hints.

### Downloads and upgrading

Windows x64: extract all files together, including WebView2Loader.dll. Microsoft Edge WebView2 Runtime is required. Mac archives are available for Apple Silicon and Intel but remain untested on real Mac hardware; grant Accessibility and any required Input Monitoring permissions.

Save drafts in every role and fully quit the old app from its tray menu before upgrading. Saved data and settings are preserved. Unsaved drafts remain memory-only and cannot survive forced termination. Builds are unsigned, Mac apps are not notarized and automatic updates are unavailable. Pasting replaces the clipboard and never sends the message.

### Verification

All three platform builds and their Node/Rust tests pass at the release commit. Archives are checked for version, CPU architecture, required contents and ZIP integrity; SHA256SUMS.txt is included.

Two local full QA runs passed 37 Node, 6 component, 36 Rust test executions (including 11 duplicated module tests), and 27 Chromium E2E cases each; one OS hotkey registration test remains ignored. Browser E2E uses an IPC double; Rust verifies native selection output. Real Mac hardware, full cross-process paste and system exit are not claimed as verified. Rust line coverage was unavailable due to a missing profiler runtime. See TEST_SUMMARY.md.
