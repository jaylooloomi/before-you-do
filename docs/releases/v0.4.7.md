## v0.4.7

### 繁體中文

- 正式版首次使用新的啟動偏好時，預設開啟「登入電腦後自動啟動」，設定頁會勾選。
- 手動取消後會記住選擇，之後開啟 App 不會再次強制啟用。啟動偏好紀錄與短句分開儲存在 `autostart.json`。
- 啟動設定仍以作業系統實際登錄狀態顯示；預覽、整合測試與開發模式不會自動新增登入啟動。
- 首次登錄失敗不會標記為已完成；偏好紀錄無法儲存時會嘗試復原原本的啟動狀態。

### English

- Enable sign-in startup by default when the release app first initializes its startup preference, with the settings checkbox reflecting the OS registration.
- Remember manual disabling instead of enabling it again on each launch. Keep the initialization record in a separate `autostart.json` file.
- Preview, integration-test and development launches do not automatically register startup.
- Failed initialization remains retryable; preference-write failures attempt to restore the previous OS startup setting.

### Verification and upgrade

Native tests cover one-time initialization, remembered choices, corrupt preference preservation, retry after failure and OS registration roundtrips. Existing snippets, drafts and unrelated settings are preserved. Login still starts in the system tray. Actual sign-out/reboot and physical Mac login testing are not claimed. Builds remain unsigned.
