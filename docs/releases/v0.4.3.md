## v0.4.3

### 繁體中文

- 在「設定與 AI 教學 → 啟動設定」加入「登入電腦後自動啟動」開關，預設關閉。
- 登入啟動只在系統匣執行；手動開啟仍顯示管理視窗。重複的登入啟動不會把已開啟的程式叫到前景。
- Windows 使用目前使用者的 Run 登錄項目，macOS 使用 LaunchAgent，無須管理員權限。
- 四語狀態與錯誤提示、儲存時停用開關，失敗時恢復原狀。啟動設定獨立於短句與草稿。

### English

- Add an opt-in automatic sign-in startup setting under Settings & AI guide → Startup.
- Login launches in the system tray. Manual launches still open the manager; duplicate login launches do not bring an existing app forward.
- Use a per-user Windows Run entry or macOS LaunchAgent, without administrator permission.
- Localize the setting in four languages, block duplicate writes and roll back failed toggles. Snippets and drafts are unaffected.

### Upgrade and verification

Save drafts in every role and fully quit the old app before upgrading. If you move the portable executable or app bundle, turn automatic startup off and on to register its new path. Disable automatic startup before deleting the app. OS Startup settings and device policies can override launch entries.

Windows registry roundtrips use an isolated test key. Tests cover quoted Unicode paths, LaunchAgent XML escaping, exact background arguments, UI persistence, four languages and error recovery. Actual sign-out/reboot and Mac hardware login behavior require a separate user session; they are not claimed as tested. Builds remain unsigned; macOS is not notarized.
