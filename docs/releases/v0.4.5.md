## v0.4.5

### 繁體中文

- 短句管理主畫面新增方向鍵操作：左右切換角色、上下選擇短句，到頭尾會循環。
- 上下鍵依搜尋結果選句並捲動至選取項目；切換角色保留各自的草稿、搜尋與選取位置。
- 編輯文字、下拉選單、設定頁、彈窗及儲存／載入期間不攔截方向鍵，避免誤切換與重複請求。
- 角色小卡上左右鍵會真正切換角色；Home／End 仍可移動小卡焦點。

### English

- Navigate the snippet manager with Left/Right for roles and Up/Down for snippets, wrapping at either end.
- Snippet navigation follows visible search results and scrolls the selected item into view. Role drafts, queries and selections are retained.
- Keep normal arrow behavior in editors, native controls, settings, dialogs and pending save/load operations.
- Left/Right on focused role cards activates the role instead of only moving card focus. Home/End retain card focus navigation.

### Verification and upgrade

Unit tests cover key guards and visible-list navigation. Browser tests exercise draft retention, per-role selection, filtering, text cursor behavior, dialogs, settings, delayed role requests and recovery from IPC errors. No OS keyboard injection is used. Save every role's drafts and fully quit before manually upgrading; snippet files and settings are not reset. Builds remain unsigned.
