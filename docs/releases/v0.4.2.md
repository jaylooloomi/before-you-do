### English

- Choose Follow system, Light or Dark. New installations follow the operating system; upgrades retain a saved theme preference.
- Correct the OpenCode preset to `opencode --auto`, alongside `/sessions` and the `[Tab]` reminder.
- Ship all 12 agent command presets and update both README languages. Existing installations do not have saved snippets overwritten or automatically expanded; add presets from the template library when wanted.

### Upgrade and verification

Save unsaved drafts in every role and fully quit the older app before upgrading. Saved snippets, settings and role files remain in the existing per-user data directory. Unsaved drafts live in memory and do not survive force termination.

The release workflow runs the Node and Rust test suites on Windows, Apple Silicon and Intel Mac runners, builds each platform package, validates archive contents and architecture, and publishes SHA256 checksums. Builds are unsigned; macOS packages are not notarized, and real Mac hardware behavior is not claimed as tested. There is no automatic updater.
