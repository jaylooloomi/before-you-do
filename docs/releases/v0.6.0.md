### English

- Named task packs keep separate materials, order and text drafts, restore the selected pack on restart, and save pending edits before switching. Failed saves keep the current pack and drafts.
- Annotate or redact static images with arrows, boxes and opaque masks. Undo/Clear apply to the editing session; Cancel discards changes. Save flattens the result to PNG and replaces the managed material.
- Material header hints now show the actual region-capture and recording start/stop bindings instead of the Alt+H snippet shortcut.
- Left-aligned material shortcut hints and a reserved bottom Delete / Save area keep actions visible while snippet content scrolls.
- Shorter bilingual READMEs explain the two core workflows, with new octopus artwork, localized screenshots and separate user guides.

### Upgrade / 升級

Save all role drafts, fully quit the old app, and back up the complete data directory before replacing the application. Windows data is in `%APPDATA%\dev.quicksay.desktop`; Mac data is under `~/Library/Application Support/dev.quicksay.desktop`.

Task packs migrate the existing material session to a collection. The first legacy read preserves its original bytes in `prompt-materials/session.legacy.json`; attachments remain in place. Older app versions cannot read the new collection format. Keep a complete pre-upgrade backup for rollback; do not open migrated materials with the old app. Snippets and preferences use their existing storage paths.

升級前請儲存所有角色草稿、完整退出 App，並備份整個資料目錄。任務包會保留既有素材，初次讀取舊格式時另存 `session.legacy.json`；新格式不能交給舊版讀取，降版請使用升級前的完整備份。短句與設定仍使用原有路徑。

### Limits / 限制

Image edits replace the app's managed copy, not the original imported file or earlier exports. Redaction is flattened pixel editing, not secure disk erasure; existing external copies remain unchanged. Animated GIF editing is excluded. Recording remains silent and Windows-only; its optional FFmpeg runtime is installed separately.

Mac packages receive CI build, architecture, archive and capture-linkage checks, but Mac hardware verification remains pending. All packages are unsigned. No automatic app update, background clipboard collection, one-action multi-attachment paste, automatic upload or automatic message sending is provided.

圖片編輯只取代 App 內素材，不會修改匯入來源或舊匯出檔；遮蔽不是安全抹除。錄影仍限 Windows 且不含聲音。Mac 仍待實機驗證，所有版本尚未簽章。發布 Release 不會自動替換正在執行的 App。
