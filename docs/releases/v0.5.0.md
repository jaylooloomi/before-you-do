## v0.5.0

### 繁體中文

- 新增本次素材：區域／全螢幕／目前視窗截圖、文字與檔案，可拖曳排序、同步編號、預覽並匯出素材包。
- Windows 支援無聲 WebM／GIF 錄製、範圍邊框、停止／暫停／取消與完成音效；錄影元件另行安裝。
- 常用短句、本次素材、設定、AI 教學分為四個分頁，統一標題位置、卡片與控制項，精簡設定與教學文案。
- 左上角產品名稱下方顯示 v0.5.0，版號直接取自專案設定；Alt+H、角色切換、短句、設定與草稿保留機制沿用。

### English

- Collect screenshots, text and files in Materials. Reorder items, keep numbering consistent, preview media and export a prompt bundle.
- Windows silent WebM/GIF recording includes a region border, stop/pause/cancel controls and completion feedback. The recording runtime is installed separately.
- Four tabs — Snippets, Materials, Settings and AI guide — share aligned headings, cards and controls, with shorter settings and guide copy.
- The version appears below the product name and comes directly from the package manifest. Existing Alt+H, roles, snippet storage and draft safeguards remain available.

### Upgrade and limitations / 升級與限制

Save drafts in every role and fully quit the old app before replacing it. Keep the existing data folder; do not delete it. Upgrading downloads does not update a running app automatically.

升級前請儲存每個角色的草稿，從系統匣完整退出舊版，再替換程式；保留原有資料夾。Release 不會自動替換正在執行的 App。

Windows has local build, browser and native feature verification. macOS packages are built and archive/architecture checked by CI; Mac hardware validation remains pending. Screenshots require macOS 14+ and screen capture permission; recording is Windows-only. All packages remain unsigned. Capture visible desktop pixels only where applicable; clipboard contents are replaced when pasting. Files stay local unless you export/share them yourself.

### Validation

Local checks: 55 JavaScript logic tests, 15 component tests and 73 Rust tests passed. The native hotkey registration conflict test remains opt-in because it temporarily registers real global keys. Browser regression covered 92 cases; the numbering drag test was adjusted to keep both drag endpoints visible and then passed twice. This change fixes the browser test's auto-scroll setup, without changing material ordering behavior. Release CI additionally builds/tests Windows and both Mac architectures, validates archive versions and architecture, and creates SHA-256 checksums. Mac hardware behavior remains unverified.
