# before-you-do v0.6.2

## 繁體中文
- 素材卡片右鍵與三點選單新增「複製」。圖片複製目前版本的像素，文字複製最新內容，GIF／影片／其他附件保留原檔格式。
- 複製前先保存素材文字草稿；複製失敗顯示提示，不移除素材。
- 可以直接拖曳整張素材卡片或圖片排序，保留原本拖曳把手與上移／下移選項。
- 排序後，卡片、預覽與匯出編號同步更新；文字編輯及影片控制不觸發拖曳排序。
- 更新中英文 README 的操作說明。

## English
- Added Copy to each material's context and three-dot menus. Copies current image pixels, the latest text, or original GIF/video/file attachments.
- Material text drafts are saved before copying. Clipboard errors leave materials intact.
- Drag cards or their images directly to reorder; existing handles and Move up/down remain available.
- Card, preview and export numbering follow the saved order. Text fields and video controls retain their normal behavior.
- Updated both README languages.

## Downloads and upgrade
Extract the Windows ZIP with WebView2Loader.dll beside the executable. macOS archives are provided for Apple Silicon and Intel; real-hardware validation is still required. Builds are unsigned and there is no automatic updater. Multi-file paste support depends on the receiving app.

Back up your data and normally exit the old app before replacing files. Existing snippets, settings and materials stay in the same dev.quicksay.desktop profile. This release does not reset custom shortcuts.
