## v0.4.6

### 繁體中文

- 修正 Alt+H 選「設定」後，管理主視窗仍出現在另一台螢幕的問題。
- 「設定」與「新增短句」會保留原始輸入視窗資訊，先將主視窗定位到該螢幕，再顯示與取得焦點。
- 主視窗維持原本的邏輯尺寸，並依目標螢幕縮放與工作區調整，避免超出螢幕或被工作列遮住。一般系統匣開啟行為不變。

### English

- Fix the manager opening on its previous display after selecting Settings from Alt+H.
- Settings and Add retain the original input target, positioning the manager on that display before showing and focusing it.
- Preserve the manager's logical size where possible and fit it to the destination work area/DPI. Normal tray opening behavior is unchanged.

### Verification and upgrade

Selection tests verify that Settings/Add retain the originating target. Layout tests cover manager bounds and mixed scaling. A preview-only native audit checks both the hidden picker and manager on both attached Windows monitors in forward and reverse order, without system input or focus changes. External chat typing/paste and physical Mac multi-monitor behavior are not claimed as manually tested.

Save drafts in every role before a manual upgrade. Saved snippets, preferences and startup registration are not reset. Builds remain unsigned.
