## English
- New eight-arm octopus icon across desktop surfaces and README titles.
- Quick materials: keyboard navigation, modifier-release actions, confirmed clear with undo, and correct dismissal when empty.
- New-install defaults: Alt+H snippets, Alt+J region capture, Alt+K quick materials, Alt+L video recording. Other material bindings are disabled. Existing custom bindings are retained.
- Attachment-only paste omits prompt.md; mixed text and attachments include it, while text-only materials paste directly.
- Dedicated shortcut tab with key recording and duplicate validation.
- Timestamped material bundles, load/add/replace/delete controls, text annotations, screenshot notifications and layout refinements.
- Tray menu: Manage snippets, Manage clipboard, Quit.

## Platform and upgrade notes
Windows is the primary tested platform. macOS builds require real-hardware verification. Builds are unsigned; there is no automatic updater. Paste inserts content without sending your AI message, and third-party apps vary in multi-file paste support.

Before upgrading, back up the data folder and quit the old app normally. User data remains in the existing dev.quicksay.desktop profile. No user snippets or material files are shipped in this release.
