# 本次素材快速面板：01 清單速覽

## 目的與邊界

以獨立、可自訂的 Alt+M 快速查看目前任務包，採用所選 01 清單概念。保留 Alt+H、Alt+V、全部資料與草稿。這不是新的素材儲存系統；面板唯讀，不刪除、不排序、不切換任務包、不自動送出訊息。

## 操作規格

- 按住 Alt+M 顯示，↑↓ 選素材、←→ 選動作；放開 Alt 執行選定動作，預設整包貼上。再次按 M 關閉取消。由工具按鈕開啟時保持顯示，不自動執行。Windows 全域註冊；其他平台不虛稱已支援全域素材快捷鍵。
- 在觸發視窗所在螢幕的工作區顯示，約 640×650，較小工作區縮小並允許清單捲動。
- 頂部：本次素材、任務包名稱、數量、目前快捷鍵。暗色圓角面板、六列以上可捲動清單，每列為縮圖／類型圖示、編號、名稱與資訊。
- ↑／↓／Home／End 選取；不循環越界。Enter 或點列開啟面板內預覽。圖片／GIF 顯示圖片，影片可播放，文字保留換行，其他檔案顯示名稱與大小。關閉／切換預覽必須停止影片。
- Esc 先關閉預覽，再關閉面板。再次按已設定的 Alt+M 關閉整個面板。
- 「整包貼上」／Alt+V：先收起面板並回到原輸入視窗，再沿用既有完整任務包貼上。不接受焦點變更後誤貼；沒有有效外部目標時僅複製，顯示回饋。
- 「開啟主視窗」：開啟本次素材分頁。主視窗草稿不重載、不捨棄。
- 開啟前由主視窗先 flush 素材文字，保存失敗不開啟空面板。擷取／錄影中不干擾現有流程。
- 空資料、讀取／預覽失敗要有狀態與重試；DOM 使用 textContent，檔名／文字不得當 HTML。
- 面板開啟時素材變更需刷新並保留仍存在的選取項目。圖片縮圖按需載入、縮小後快取；不一次載入所有原圖／影片。
- 四語文案；熱鍵設定新增一列，沿用錄製、重複檢查、還原與停用確認。舊設定若 Alt+M 已被其他動作使用，不覆蓋既有綁定。
